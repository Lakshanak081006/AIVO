# Existing and Proposed System

## Existing system
Users independently search transport sites, hotel sites, weather applications and maps. Information is fragmented, changes are handled manually, and decisions are rarely explained.

## Proposed system
A coordinator agent creates a dependency-aware task plan. Transport, Hotel, Weather and Attraction agents run concurrently. Itinerary and Budget agents combine their results. A Replanning Agent changes only affected decisions after a disruption. All actions are stored in a transparent log.
