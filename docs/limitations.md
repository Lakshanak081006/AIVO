# Limitations

- Travel, booking, payment and weather services are simulated for safe academic demonstration.
- Natural-language fallback parsing supports the documented cities and common request structures.
- Tamil and Hindi UI text is partially handled through language-aware input and output fields; full production localization would require larger translation catalogs.
- The included SSE endpoint replays persisted workflow events because the complete demo workflow finishes synchronously.
- No real money, ticket or hotel transaction occurs.
