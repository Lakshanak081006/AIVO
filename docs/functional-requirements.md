# Functional Requirements

1. Register and authenticate users.
2. Maintain travel preferences.
3. Accept text or voice instructions.
4. Detect English, Tamil or Hindi.
5. Extract structured travel requirements.
6. Ask only essential clarification questions.
7. Create prioritized tasks and dependencies.
8. Search simulated transport, hotels, weather and attractions.
9. Execute independent agents concurrently.
10. Rank options and explain recommendations.
11. Generate a realistic day-wise itinerary.
12. Calculate and validate the budget.
13. Generate cheaper alternatives.
14. Record progress, events and action logs.
15. Replan for cancellations, rain, unavailable hotels and changed constraints.
16. Require confirmation before simulated booking.
17. Store feedback and request approval before learning preferences.
