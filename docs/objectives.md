# Objectives

## Main objective
Develop an autonomous personal assistant capable of completing a multi-step travel-planning goal from a single natural-language request.

## Specific objectives

- Extract source, destination, dates, travellers, budget and preferences.
- Execute independent search tasks in parallel.
- Rank transport and hotel options with explainable scoring.
- Adapt attractions and schedules to weather.
- Calculate a complete budget and propose cheaper alternatives.
- Retry failed tools, use fallback data and dynamically replan.
- Track state, tasks, logs, versions, confirmations and feedback.
- Support voice input and English, Tamil and Hindi requests.
