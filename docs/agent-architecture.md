# Agent Architecture

- **Coordinator Agent:** controls execution, state, events and final summary.
- **Requirement Agent:** detects language and extracts structured constraints.
- **Planner Agent:** creates priorities, dependencies and parallelizable tasks.
- **Transport Agent:** searches and ranks trains, buses and flights.
- **Hotel Agent:** ranks accommodation by cost, rating, distance and amenities.
- **Weather Agent:** evaluates daily outdoor suitability.
- **Attraction Agent:** filters closed or weather-unsuitable locations.
- **Itinerary Agent:** creates non-overlapping daily activities and meal breaks.
- **Budget Agent:** calculates all cost categories and reserve.
- **Alternative Agent:** reduces cost when the budget is exceeded.
- **Replanning Agent:** responds to disruptions and creates a new plan version.
- **Feedback Agent:** proposes reusable preferences that require approval.
