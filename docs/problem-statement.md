# Problem Statement

Everyday travel planning requires switching between multiple applications to compare transport, accommodation, weather, attractions and cost. Users must manually manage dependencies, recover from unavailable services and rebuild the plan when conditions change.

This project provides an Agentic AI personal assistant that accepts one high-level instruction and autonomously decomposes it into tasks, runs specialized agents, compares options, builds an itinerary, validates the budget, recovers from failures and explains its decisions.
